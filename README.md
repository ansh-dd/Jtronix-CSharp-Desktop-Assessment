# JTRONIX C# Desktop Internship Assessment

A single C# Windows Forms application that implements all three tasks from the JTRONIX C# Desktop Internship Assessment.

## Requirements

- Windows 10/11
- Visual Studio 2022 Community (or newer)
- **.NET desktop development** workload
- .NET 8 SDK

## Implemented assessment tasks

### 1.1 Button Click Event
- Button text: `Click Me`
- Clicking the button displays: `Hello, Welcome to C#!`

### 1.2 Change Button and Label Text
Initially:
- Button: `Click Me`
- Label: `Welcome`

After clicking:
- Button: `Clicked`
- Label: `Button clicked successfully!`

### 1.3 Student GridView and Search
- Displays student records using a `DataGridView`
- Columns: `Roll Number` and `Student Name`
- Search textbox and Search button
- Searches by roll number
- Displays matching student name
- Displays `Student not found` if the roll number does not exist

## How to run

1. Extract the ZIP.
2. Open `JtronixCSharpAssessment.sln` in Visual Studio.
3. If Visual Studio asks to install missing components, install the **.NET desktop development** workload and .NET 8 SDK.
4. Build the solution with `Ctrl + Shift + B`.
5. Run with `F5`.
